# Yoke — ручний QA-чеклист

Проходь зверху вниз, познач **OK / FAIL** і пиши, що зламано чи чого бракує.
Легенда: 🔌 потребує реального провайдера/мережі · 🧪 чистий UI/CLI (без LLM) · ⚠️ гейт/негатив-кейс.

**Підготовка (опційно, щоб не чіпати реальний ~/.yoke):**
```bash
export YOKE_HOME=$(mktemp -d /tmp/yoke-qa-XXXX)   # ізольований стор на час тесту
./yoke serve --port 8799 --open                   # НЕ 8765, щоб не конфліктувати
```
Або просто `./yoke` на дефолтному 8765, якщо хочеш ганяти на справжніх даних.

## Куди писати знахідки
Під кожним FAIL — що очікував, що сталось, кроки відтворення. Те, чого **бракує** (а не зламано) —
окремим списком унизу як «бэклог». Відомі межі вже зафіксовані в `docs/test-scenarios.md` (секція прогалин):
comp-«est» не ретроактивний; B-вхід (сорси не-ICP); remote+interested порожній комбо показує картку, не редіректить.
